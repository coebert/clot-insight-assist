# Clot Clarity

I want to build a new app that will automatically interpret the results of a thromboelastogram (specifically from the TEG 6 machine) and advise on whether specific blood products should be given, and if so, which ones. The app should be able to access the camera of a mobile device and detect the relevant values displayed on the TEG machine's display. It should then be able to interpret these numbers using a validated algorithm from a reputable source to then advise on what blood products, if any, are needed
